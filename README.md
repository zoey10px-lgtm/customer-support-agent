# 온라인 배포용 버전

온라인 배포는 `DEPLOY_RENDER.md`를 먼저 확인하세요. 외부 접속·HTTPS·시연 접속 코드와 호출 제한을 추가했습니다.
로컬 실행 방법과 홈페이지 기능은 아래와 같습니다.

# SEMILON Electronics + Carely

세밀론 일렉트로닉스 회사 홈페이지와 기업 고객 품질지원 Agent를 합친 로컬 실행 프로젝트입니다.
Python 3.10 이상이면 실행됩니다. 추가 Python 패키지나 Node 설치가 필요하지 않습니다.

## 바로 실행

1. ZIP을 새 폴더에 전부 압축 해제합니다. `public`, `data`, `tests` 폴더 구조를 유지하세요.
2. 기존에 사용한 `.env`를 새 폴더의 `server.py` 옆에 복사합니다.
3. Windows에서 `start.cmd`를 실행합니다.
4. 브라우저가 자동으로 열립니다. 주소: http://127.0.0.1:8770
5. 처음에는 회사 홈페이지가 표시됩니다. 상단의 고객지원 메뉴를 누르면 Carely로 이동합니다.

기존 8000/8766 포트와 구분하도록 새 실행 파일은 8770을 사용합니다.
파일을 수정한 뒤에는 검은 서버 창을 Ctrl+C로 종료하고 다시 실행하세요.
홈페이지를 보려면 파일을 직접 더블클릭하지 말고 위 서버 주소로 접속하세요.

macOS/Linux: 프로젝트 폴더에서 `python3 server.py`를 실행하세요.
실제 키는 포함하지 않았습니다. 새 설정이 필요하면 `.env.example`을 `.env`로 복사해 설정하세요.

## 홈페이지

- `/`: 심플한 타이포그래피 배너, 제품 3종, 회사·품질·가치 소개, Carely 연결
- `/company.html`: 회사 소개와 핵심 가치
- `/products.html`: 제품 사진, 소재·용도·품질 확인 항목·제조 공정, 제품별 문의 연결
- `/quality.html`: 외관, 규격, 이력, 담당자 승인 중심의 품질 대응
- `/support.html`: 기존 다국어 Agent와 사진 첨부 분석 통합
- 모든 페이지: 한국어 / English / Tiếng Việt, 모바일 메뉴, 프로필과 개인정보 안내

요청하신 세 제품 사진만 사용했습니다. 앞서 생성한 배너·사람 사진은 사용하지 않았습니다.
메인 배너는 CSS와 실제 텍스트로 구현했으며 스크롤 등장 효과와 축소 화면 대응을 추가했습니다.
동작 줄이기 환경 설정에서는 애니메이션을 끕니다.
제품 사진은 가상 제품 콘셉트입니다. 회사·거래처·검사 기록은 해커톤 시연용 가상 자료입니다.
원본 JSON에서 회사 표시 이름만 세밀론으로 맞췄으며 제품 코드와 자료 ID는 유지했습니다.

## 고객지원과 사진

- 기존 불만 분류 → 자료 조회 → 원인 후보·대책 → 고객 회신 초안 흐름 유지
- 영어·베트남어 입력을 검색용 한국어로 변환, 최종 답변은 선택 언어로 작성
- 사진 드래그앤드롭/선택, 미리보기, 개별 삭제
- JPG/JPEG, PNG, WebP 최대 3장, 장당 5MB
- 사진 API 분석 → 구조 검증된 불량 유형 후보 → 로컬 JSON 검색 → 최종 회신
- 관찰 결과, 고객 제보, 사내 검사 기록을 구분하도록 지시
- 사진만으로 LOT·제품 코드를 추정해 매칭하지 않으며, 정확한 치수나 원인을 단정하지 않음
- 정상/판독 불가/무관한 사진은 억지로 불량 키워드를 추가하지 않음
- 답변 읽기/편집 전환, 복사, 근거 자료 확인, 추가 대화
- 추가 대화에는 앞서 받은 사진 관찰 요약을 전달하며 이미지 자체를 재전송하지 않음
- 사진과 문의는 서버에 파일로 저장하지 않음

`.env`의 OPENAI_MODEL은 기존 값을 사용합니다. 사진에는 이미지 입력을 지원하는 모델이 필요합니다.
이미지를 지원하지 않는 모델에서 발생하는 API 오류는 확인 안내로 표시합니다.
실제 API 호출 검증과 사진 판독 품질 검증은 수행하지 않았습니다.

## 프로필과 문의 기록

상단 사람 아이콘에서 이름·소속 회사·선호 언어를 저장할 수 있습니다.
분석에 성공한 문의는 최근 20건까지 이 브라우저에 저장됩니다.
기록 보기, 이전 문의 이어가기, JSON 다운로드, 기록 삭제가 가능합니다.
사진 원본은 문의 기록에 저장하지 않으며 관찰 요약만 저장합니다.
프로필은 브라우저 로컬 기능이며 로그인이나 다른 기기 동기화는 구현하지 않았습니다.

## API와 데이터 전송

홈페이지 탐색과 프로필은 API를 호출하지 않습니다.
민원 분석 시 입력 내용, 선택 사진과 필요한 조회 자료가 OpenAI로 전송됩니다.
- 한국어 글만: 보통 1회
- 외국어 글: 보통 번역 + 회신, 2회
- 사진 첨부: 사진 분석 1회 추가
비용·속도는 모델과 이미지 크기에 따라 달라집니다. 합산 토큰 사용량을 표시합니다.
고객 회신은 자동 발송하지 않습니다. 담당자가 초안을 확인·수정합니다.

## 팀원 작업 연결

LOT 정규화·정교한 민원 판별·메일/PDF 입력은 담당 팀원이 확장할 수 있습니다.
기존 함수 `retrieve`, `prepare_search_text`, `call_openai`를 유지했습니다.
`/api/analyze`는 기존 필드에 `images: [{name, data_url}]`을 선택적으로 받습니다.
응답은 기존 answer/usage/sources에 image_analysis를 추가합니다.
사진 없는 기존 클라이언트도 그대로 동작합니다.

## 검증

프로젝트 폴더에서:

    python -m unittest discover -s tests -v

18개 테스트: 기존 검색·다국어·HTTP·설정 오류, 회사 페이지·사진 정적 파일,
사진 전달 → 관찰 결과 → 자료 조회 흐름, 사진 제한, 잘못된 관찰 응답 차단.
추가 DOM 테스트로 5개 페이지 메뉴, 3개 언어, 프로필 저장, 사진 선택/전달,
편집·추가 대화·문의 기록을 검증했습니다.
시각 렌더링은 브라우저 실행 환경이 없어 검증하지 못했습니다.

- `public/site.js`: 공통 메뉴·페이지·프로필·문의 기록
- `public/site.css`: 데스크톱/태블릿/모바일 디자인과 애니메이션
- `public/app.js`, `public/i18n.js`: Carely 동작·언어·사진 첨부·결과 표시
- `public/assets/`: 승인한 제품 이미지 3장
- `data/`: 가상 제조 품질 JSON
- `tests/`: 모의 API 기반 검증
